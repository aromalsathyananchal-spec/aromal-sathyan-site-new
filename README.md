# Aromal Sathyan | Combined Site

One-page site combining freelance services, professional experience and MBA projects.
Next.js (App Router), TypeScript, Tailwind CSS, Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Customise

- **All content:** `data/site.ts` (source: Aromal_Sathyan_CV_NEW.pdf). Services are draft wording to confirm.
- **Photo:** `public/profile.jpg`. **CV:** `public/Aromal_Sathyan_CV.pdf`.
- **Colours:** `tailwind.config.ts` (accent `#F0004F`, estimated from the reference screenshot).
- **Site URL:** set `NEXT_PUBLIC_SITE_URL` in Vercel.

## Deploy

Push to GitHub, import in Vercel, click Deploy.
